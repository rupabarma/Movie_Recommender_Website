# Movie Recommendation System

A content-based movie recommendation website built with **Python, Flask, Pandas, and scikit-learn**. Select a movie from the available titles and the application returns five movies with similar content.

## Overview

This project recommends movies by comparing information associated with each title. The model-building notebook combines movie overviews, genres, keywords, cast members, and directors into a text field called `tags`. It then converts those tags into numerical features and calculates pairwise cosine similarity.

The Flask web application loads the prepared movie data and similarity matrix, accepts a movie title from the website, and returns the five most similar titles.

## Features

- Search for a movie using an input field with title suggestions.
- Generate five recommendations for a selected movie.
- Content-based recommendation using movie metadata.
- Text preprocessing and stemming with NLTK.
- Bag-of-words feature extraction with `CountVectorizer`.
- Cosine similarity to compare movies.
- Flask backend with an HTML/CSS frontend.

## Dataset

The project includes two CSV files from the TMDB 5000 movie dataset:

- `tmdb_5000_movies.csv` — movie metadata, including overview, genres, keywords, and title.
- `tmdb_5000_credits.csv` — cast and crew information.

The notebook merges the files using the `title` column and selects the fields needed for recommendation. The CSV files each contain 4,803 records.

## How the Recommendation Model Works

The model is developed in `Model.ipynb` and follows these steps:

1. **Load the data:** Read the movies and credits CSV files with Pandas.
2. **Merge the datasets:** Combine movie metadata with cast and crew information.
3. **Select features:** Keep the movie ID, title, overview, genres, keywords, cast, and crew.
4. **Clean the data:** Remove rows with missing values and duplicate rows.
5. **Extract metadata:** Parse genres and keywords, take up to three cast members, and extract the director.
6. **Create tags:** Combine the overview, genres, keywords, cast, and director into one text field.
7. **Normalize text:** Convert tags to lowercase, remove spaces within names, and apply Porter stemming.
8. **Vectorize text:** Use `CountVectorizer` with a maximum of 5,000 features and English stop-word removal.
9. **Calculate similarity:** Use cosine similarity to calculate similarity scores between movie vectors.
10. **Save model artifacts:** The notebook saves the processed movie data to `movies.pkl` and the similarity matrix to `similarity.pkl`.

When a user selects a movie, the application finds its row in the movie data, sorts the similarity scores, skips the selected movie itself, and returns the next five titles.

## Installation and Setup

### 1. Clone the repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd Movie_Recommender_Website
```

Alternatively, download and extract the project ZIP, then open the extracted folder in a terminal.

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate the virtual environment

**Windows (Command Prompt):**

```bash
venv\Scripts\activate
```

**Windows (PowerShell):**

```powershell
.\venv\Scripts\Activate.ps1
```

**macOS / Linux:**

```bash
source venv/bin/activate
```

### 4. Install dependencies

After creating a `requirements.txt` file containing the project's dependencies, run:

```bash
pip install -r requirements.txt
```

The application and notebook use Flask, Pandas, NumPy, scikit-learn, and NLTK. Jupyter Notebook is also needed if you want to run `Model.ipynb`.

### 5. Generate the model files

If the required `similarity.pkl` file is not available:

1. Start Jupyter Notebook from the project directory:

   ```bash
   jupyter notebook
   ```

2. Open `Model.ipynb`.
3. Run the notebook cells from top to bottom.
4. Confirm that `movies.pkl` and `similarity.pkl` are generated in the project root.

The notebook uses the included CSV files as its input.

### 6. Run the Flask application

Once `movies.pkl` and `similarity.pkl` are present in the project root:

```bash
python App.py
```

Open the local address shown in the terminal. With the current Flask configuration, it is normally:

```text
http://127.0.0.1:5000/
```

## How to Use

1. Open the website in your browser.
2. Enter a movie title in the search field. The input provides title suggestions from the loaded movie dataset.
3. Select or type a title that exactly matches a title in the dataset.
4. Click **Recommend**.
5. The page displays up to five recommended movie titles.

The recommendation endpoint is:

```text
POST /recommend
```

It accepts a form field named `movie` and returns a JSON array of recommended movie titles.

## Important Implementation Notes

- Movie-title matching in the current backend is exact and case-sensitive. Use a title as it appears in the suggestion list.
- The current recommendation function returns an empty list if the submitted title is not found.
- The application expects the pickle files to be in the working directory from which `App.py` is run. Run the command from the project root.
- `App.py` currently starts Flask with `debug=True`. Debug mode is intended for local development and should be disabled for production deployment.
- Pickle files should only be loaded from sources you trust. Loading an untrusted pickle file can execute malicious code.
- The supplied `.gitignore` excludes `.pkl` files. If you keep that rule, the generated model artifacts will not be included in GitHub; users or the deployment process will need to generate or obtain them separately.

## Current Limitations

- Recommendations are based on metadata text, not user ratings or viewing history.
- The application displays movie titles only; it does not currently show posters, descriptions, ratings, or streaming availability.
- The model uses a bag-of-words representation, so it does not understand semantic meaning in the way modern embedding-based systems do.
- The current interface does not display a dedicated error message for an empty or invalid movie title.

## Possible Future Improvements

- Add robust input validation and user-friendly error messages.
- Make movie-title matching case-insensitive.
- Display movie posters, genres, release years, and descriptions.
- Add filters for genre, language, and release year.
- Explore TF-IDF or semantic embeddings as alternatives to the current bag-of-words representation.
- Add automated tests for the recommendation function and Flask routes.
- Configure production deployment with debug mode disabled and a production WSGI server.
